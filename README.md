## About StatLume

StatLume displays recent YouTube Studio activity directly on the user's Windows desktop. The application does not require a StatLume account or a StatLume-operated backend server.

StatLume is an independent application and is not affiliated with, endorsed by, sponsored by, or officially connected with Google LLC or YouTube.
