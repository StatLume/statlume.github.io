Time periods

Last 48 hours

Automatic continuity

If Studio is unavailable, StatLume keeps the last valid snapshot visible and retries at controlled intervals.

LIVE and OFF states

The status makes it clear whether the screen contains fresh Studio data or the latest saved snapshot.

Studio remains the source

Responses from the authenticated Studio page are processed locally on your computer.

How it works

Your Studio session stays in control.

Sign in through the embedded Chromium browser. Google handles authentication, while StatLume presents the useful realtime fields in the desktop widget.

Studio changes can affect availability because StatLume is independent and is not affiliated with or endorsed by Google or YouTube.
