# StatLume Support

## Getting help

For support, open an issue in the official StatLume documentation repository:

https://github.com/StatLume/statlume.github.io/issues

When reporting a problem, please include:

- StatLume version;
- Windows version;
- a short description of the issue;
- whether YouTube Studio opens and signs in successfully;
- a screenshot of the widget or error, if appropriate.

Do not send passwords, authentication cookies, session tokens, or other account credentials.

## Common issues

### StatLume shows Offline

Open YouTube Studio through StatLume and verify that the account is still signed in. If YouTube requires authentication again, sign in through the embedded browser.

### Realtime statistics stop updating

YouTube Studio may change its internal interfaces or temporarily stop returning the information used by StatLume. Restart StatLume and reconnect the Studio session. If the issue continues, check for a newer StatLume version.

### Changing YouTube accounts

Use the Disconnect option in StatLume, then connect again and sign in with the desired Google/YouTube account.

### Privacy and local data

StatLume does not operate a backend server for user analytics or authentication data. See the Privacy Policy for details.
