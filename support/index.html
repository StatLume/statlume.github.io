Support

Send a support request directly from the StatLume website.

Do not include passwords, authentication cookies, session tokens, API keys, or other account credentials.

Common issues

StatLume shows OfflineOpen YouTube Studio through StatLume and verify that the account is still signed in.
Realtime statistics stop updatingRestart StatLume and reconnect the Studio session. YouTube Studio changes can temporarily affect StatLume.
Changing YouTube accountsUse Disconnect in StatLume, then connect again with the desired account.
