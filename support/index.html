Common issues

Quick answers for the questions that come up most often when setting up StatLume or changing how the widget behaves.

What does “OFF” mean?

StatLume keeps showing your last valid snapshot when YouTube Studio is temporarily unavailable. It retries automatically and returns to LIVE when fresh data is available.

Which realtime periods can I view?

Switch between the latest minute, 60 minutes, and 48 hours in Settings → View period.

How do I change the widget view?

Right-click the widget to choose Compact, Normal, or Fullscreen. Double-clicking also moves between the focused views.

How do I switch YouTube accounts?

Choose Disconnect account, connect again, and sign in with the channel you want to use.

Can StatLume start automatically?

Yes. Enable Start with Windows in Settings. Store and portable installations use the appropriate Windows startup method.
