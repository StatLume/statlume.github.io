Quick answers

Common issues

What does “OFF” mean? +

StatLume keeps showing your last valid snapshot when YouTube Studio is temporarily unavailable. It retries automatically with increasing delays and returns to LIVE as soon as fresh data is available. If OFF remains, open YouTube Studio through StatLume and check that you are still signed in.

Which realtime periods can I view? +

You can switch between the latest minute, 60 minutes, and 48 hours in Settings → View period. The chart, total, and video breakdown update for the selected period when that data is available from YouTube Studio.

How do I change the widget view? +

Right-click the widget to choose Compact view, Normal view, or Fullscreen. Double-clicking the normal widget opens Fullscreen; double-clicking the compact widget returns to Normal view.

How do I switch YouTube accounts? +

Choose Disconnect account, then connect again and sign in with the channel you want to use. Disconnecting clears cached channel data and removes the local YouTube Studio browser profile after it is released by the app.

Can StatLume start automatically? +

Yes. Enable Start with Windows in Settings. Microsoft Store installations use the Windows Startup Apps setting; portable installations use the current user’s startup configuration.
