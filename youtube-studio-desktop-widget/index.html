YouTube Studio desktop widget for Windows.

A dedicated Windows view that stays beside your editing, streaming, and publishing tools.

Explore StatLume features

Use only the screen space you want.

Move the frameless widget wherever it fits. Keep it above other windows, adjust opacity, or hide the video list when the live total is all you need.

StatLume can start with Windows and restore the view you prefer.

Normal

Channel identity, realtime total, chart, subscribers, and a recent video breakdown.

Compact

A minimal count designed to sit near another application without taking over.

Fullscreen

A clean presentation view for a second display, studio wall, or focused monitoring.

Taskbar counter

Keep the latest count available from the Windows taskbar when enabled in Settings.

Flexible placement

Position the widget freely, adjust opacity, and enable Always on top when needed.

Start with Windows

Launch StatLume automatically and return to the view that fits your workflow.

Sign in through YouTube Studio itself.

Disconnect account clears cached channel data and schedules that local browser profile for deletion.
