Desktop widget

Keep channel activity in sight while you work.

StatLume turns YouTube Studio realtime analytics into a dedicated Windows widget that can stay beside your editing, streaming, and publishing tools.

View all features

Three layouts

Use only the screen space you want.

Normal

Channel identity, realtime total, chart, subscribers, and a recent video breakdown.

Compact

A minimal count designed to sit near another application without taking over.

Fullscreen

A clean presentation view for a second display, studio wall, or focused monitoring.

Taskbar counter

Keep the latest count available from the Windows taskbar when enabled in Settings.

Workspace

Designed to remain useful in the background.

Move and place it freely

Position the frameless widget where it fits your setup. Enable Always on top when the number should remain visible above other windows.

Adjust the presentation

Change opacity, show or hide the video list, select a realtime period, and move between display modes from the widget menu.

Start with Windows

StatLume can launch automatically. Microsoft Store installations use the Windows Startup Apps system; portable installations use the current-user startup configuration.

Connection

Sign in through YouTube Studio itself.

StatLume opens an embedded Studio browser where Google handles authentication. The browser profile is stored locally so Studio can remain signed in between sessions.

Choose Disconnect account to clear cached channel data and schedule that local browser profile for deletion.
