# Privacy Policy for StatLume

Last updated: September 16, 2026

StatLume is a Windows desktop application that displays YouTube Studio statistics directly on the user's device.

## 1. Data collection

StatLume does not operate its own backend server and does not send the user's YouTube Studio statistics, Google credentials, YouTube credentials, browser session data, or authentication cookies to the developer.

The developer does not collect, sell, rent, or use this information for advertising, profiling, analytics, or marketing.

## 2. YouTube Studio sign-in

Users sign in to YouTube Studio through an embedded browser window.

Authentication is performed by Google and YouTube within that browser session.

StatLume does not receive or store the user's Google or YouTube password.

## 3. Local session data

To keep the user signed in and provide the application's functionality, the embedded browser may store session information locally on the user's Windows device, including browser cookies and related session data.

This information remains on the user's device and is not transmitted to a server operated by the developer.

## 4. Local application data

StatLume may store application settings and locally cached information required for the widget to operate, such as:

- channel name or channel identifier;
- subscriber count;
- channel avatar or locally cached avatar data;
- video titles or identifiers;
- recent statistics and cached realtime snapshots;
- application preferences and display settings.

This information is stored locally on the user's device.

## 5. How data is used

Local session and channel data is used only to provide StatLume functionality, including displaying the user's YouTube Studio statistics and preserving application preferences.

The developer does not receive the user's YouTube Studio analytics or session information.

## 6. Third-party services

StatLume interacts with Google and YouTube services when the user signs in and while the application retrieves information from the authenticated YouTube Studio session.

Use of Google and YouTube services is also subject to their respective terms and privacy policies.

## 7. Disconnecting YouTube Studio

StatLume provides a way to disconnect the local YouTube Studio session.

Disconnecting removes session information managed by the application to the extent supported by the installed version. Users may also remove remaining local application data through Windows application settings or by uninstalling StatLume.

## 8. Data sharing

StatLume does not sell or share the user's personal data with advertisers, data brokers, or marketing companies.

Because StatLume does not operate a developer-controlled backend, the developer does not receive the user's local YouTube Studio session or channel statistics through normal application use.

## 9. Security

StatLume is designed so that authentication and session information remains on the user's local device. Users are responsible for maintaining the security of their Windows account and device.

## 10. Children's privacy

StatLume is not designed to knowingly collect personal information from children. The developer does not operate a server that collects user profile or YouTube Studio session data.

## 11. Changes to this Privacy Policy

This Privacy Policy may be updated if StatLume's functionality or data handling changes.

The current version will be published at the Privacy Policy URL associated with StatLume.

## 12. Contact

For privacy questions or support, open an issue in the official StatLume documentation repository:
